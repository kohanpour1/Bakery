# Bakery Time Online (پایش عملکرد کارکنان)

نسخه وب مستقل برای مدیریت کاربران و وظایف، ثبت تاریخچه، گزارش مدیریتی و اجرای محاسبه‌گر ساعت کاری نسخه ۵.

## پیش‌نیاز
- Node.js 20 یا 22
- Linux VPS/سرور یا Windows Server
- دامنه/زیر دامنه و HTTPS برای استفاده واقعی

## اجرای آزمایشی
1. Node.js 20+ نصب کنید.
2. پوشه را باز کنید و `npm install` اجرا کنید.
3. `.env.example` را به `.env` کپی کنید و `SESSION_SECRET` را با مقدار تصادفی طولانی جایگزین کنید.
4. در اجرای نخست، مدیر ساخته می‌شود: `kohanpour` / رمز اولیه `1`. مدیر باید بلافاصله رمز را تغییر دهد.
5. `npm start` اجرا کنید و به `http://localhost:3000` بروید.

## اجرای Docker
- فایل `.env` را ایجاد کنید (از `.env.example` الگوبرداری کنید).
- `docker compose up -d --build`
- داده‌ها در پوشه `data/` نگهداری می‌شوند. از این پوشه نسخه پشتیبان تهیه کنید.

## ساختار
- `server.js`: API، احراز هویت، کنترل نقش، پایگاه داده و رویدادها
- `public/`: رابط وب و محاسبه‌گر HTML
- `data/bakerytime.sqlite`: پایگاه داده کاربران/وظایف/رویدادها (پس از اجرا ایجاد می‌شود)
- `deploy/`: نمونه تنظیمات Nginx

## نکات امنیتی
- رمزها با bcrypt هش می‌شوند و در دیتابیس متن ساده ذخیره نمی‌شوند.
- نشست HttpOnly و SameSite=Lax است و در حالت production کوکی Secure می‌شود.
- نقش مدیر در سرور بررسی می‌شود. مشاهده پنل کارمند توسط مدیر از طریق API مدیریت و بدون رمز کارمند انجام می‌شود و در لاگ مدیریتی ثبت می‌شود.
- رمز اولیه `1` صرفاً برای نصب اولیه است؛ سامانه تغییر رمز مدیر را الزامی می‌کند. پیش از انتشار عمومی، `SESSION_SECRET` قوی تنظیم کنید و HTTPS را فعال کنید.
- این نسخه پایه اجرایی است. برای سازمانی/عمومی شدن، HTTPS، سیاست نگهداری داده، محدودسازی شبکه، بررسی امنیت مستقل و پشتیبان‌گیری منظم لازم است.
