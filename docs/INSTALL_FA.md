# راهنمای نصب Bakery Time Online

## نصب با Node.js
1. Node.js نسخه 20 یا جدیدتر را نصب کنید.
2. فایل‌ها را در یک پوشه (مثلاً `C:\BakeryTime` یا `/opt/bakerytime`) استخراج کنید.
3. ترمینال را در همان پوشه باز کرده و `npm install` اجرا کنید.
4. `.env.example` را به `.env` تغییر نام/کپی دهید.
5. در `.env` مقدار `SESSION_SECRET` را با رشته تصادفی طولانی جایگزین کنید. برای نمونه با دستور `openssl rand -hex 48` تولید کنید.
6. اجرای `npm start`.
7. در مرورگر `http://localhost:3000` را باز کنید.
8. ورود اولیه مدیر: نام کاربری `kohanpour` و رمز `1`؛ پس از ورود، تغییر رمز اجباری است.

## Docker
1. Docker و Docker Compose را نصب کنید.
2. `.env` را ایجاد و `SESSION_SECRET` را تنظیم کنید.
3. در پوشه پروژه: `docker compose up -d --build`.
4. بررسی اجرا: `docker compose logs -f`.
5. توقف: `docker compose down` (داده‌های پوشه data باقی می‌ماند).

## ایجاد کارمند و وظیفه
- از پنل مدیر، کارمند را با نام، نام کاربری و رمز اولیه ایجاد کنید.
- رمز اولیه باید حداقل ۸ نویسه باشد؛ کارمند بعد از ورود رمز خود را تغییر دهد.
- وظیفه، شرح و موعد را ثبت کنید. وضعیت و یادداشت هنگام تغییر وضعیت ثبت می‌شود.
- در بخش بازبینی کارمند، پنل/وظایف و تاریخچه کارمند بدون ورود با حساب او مشاهده می‌شود. این بازبینی فقط برای مدیر و با دسترسی سرور مجاز است.

## تغییر رمز
کارمند یا مدیر از تب «تغییر رمز» رمز فعلی و رمز جدید را وارد می‌کند. مدیر برای کارمند می‌تواند از پنل مدیر رمز موقت تعیین کند؛ کارمند پس از ورود باید رمز را تغییر دهد.
