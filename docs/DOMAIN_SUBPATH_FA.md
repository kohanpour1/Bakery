# راهنمای دامنه مستقل یا نصب در زیرمسیر سایت

## دامنه یا زیردامنه مستقل (پیشنهادی)
برای مثال `monitor.example.com`:
1. دامنه را به IP سرور (DNS A) متصل کنید.
2. برنامه را با `BASE_PATH=/` و روی پورت داخلی 3000 اجرا کنید.
3. Nginx را با نمونه `deploy/nginx-domain.conf` تنظیم کنید.
4. HTTPS را با Certbot/گواهی معتبر فعال کنید.
5. پس از نصب، لینک دامنه را باز کنید و مدیر را وارد نمایید.

## نصب در زیرمسیر سایت موجود
برای مثال `example.com/bakerytime/`:
1. `.env` را تنظیم کنید: `BASE_PATH=/bakerytime`.
2. برنامه را روی پورت داخلی 3000 اجرا کنید.
3. قطعه نمونه `deploy/nginx-subpath.conf` را به تنظیمات سایت اضافه کنید. این نمونه مسیر `/bakerytime/` را به برنامه منتقل می‌کند.
4. اگر سایت شما Apache یا کنترل‌پنل هاست است، باید reverse proxy فعال باشد؛ صرف آپلود فایل HTML روی هاست اشتراکی، API و پایگاه داده را اجرا نمی‌کند.
5. پس از اتصال، آدرس `/bakerytime/` را باز کنید.

## افزودن لینک سرور در آینده
در این نسخه آدرس API در مسیر همان نصب قرار دارد و به‌صورت خودکار از URL فعلی استفاده می‌کند. برای جابه‌جایی سرور، فایل‌ها را روی سرور جدید نصب، داده SQLite را منتقل و DNS/Reverse Proxy را تغییر دهید؛ لازم نیست کد frontend را دستکاری کنید.
